FlipMirror

把已拆除内屏的 Galaxy Z Flip5（SM-F731N）变成一台可用的外屏手机 —— 通过 MediaProjection 把 display 0 的画面投到外屏 display 1，并把外屏触摸反向注入回内屏。

二、文件清单

文件职责关键约束
MainActivity.java唯一入口：申请录屏授权 → 预置 device_state/分辨率 → shell 拉起镜像页必须 exported=true + launchMode=standard，否则 shell 拉起被拒或复用旧实例
MirrorActivity.java镜像主界面：SurfaceView + 圆角 + 手势排除 + 触摸转发wm size/density 必须在拉起前设好，运行期间改会触发重建 → 落回 display 0
MirrorEngineImpl.javaMediaProjection → createVirtualDisplay(AUTO_MIRROR)同一 resultData 只能建一次，重复建抛 SecurityException
MirrorService.java前台服务，持有 mediaProjection 类型stopWithTask=false
BarOverlayService.java右上角悬浮控件条 + 圆角遮罩只在镜像运行时存在，退出即移除
ControlBar.java自绘四键 ‹ ○ ▢ ✕图标统一 16×16 视觉盒
TouchInjectorImpl.java触摸注入：优先 UserService，兜底 shell 命令必须实时发 DOWN/MOVE/UP；MOVE 40ms 节流
TouchUserService.java常驻 shell 进程里的注入端必须继承 ITouchUserService.Stub，不能是 Service
ITouchUserService.aidl注入接口纯 ASCII，中文注释会让 aidl.exe 失败
Shell.java统一 shell 通道root 先试 6 个绝对路径；失败退 Shizuku；要求 exitCode==0 才算成功
SettingsStore.java参数：内屏 W/H/DPI、圆角半径、DPI 滑块默认 1600×1398 @480
WatchdogService.java独立进程 :wd 守护（异常退出后重新拉起）--ez auto_start true 免点击
install.sh装包 + 授权 appops + 复查不碰用户系统偏好（导航方式等）
flip-boot.bat开机后一键起 Shizuku + 拉镜像纯 ASCII

三、数据契约

键 / 值含义默认
innerWidth / innerHeight内屏被压缩后的像素尺寸（必须保持 748:654 ≈ 1.144 的比例）1600 / 1398
innerDpi内屏密度。dp = px ÷ (dpi/160)；调小 → 一屏显示更多480
cornerRadius圆角半径（基准 748 宽，实际按比例缩放）48
device_state镜像期间必须为 4（CONCURRENT_INNER_DEFAULT）；退出改回 1退出 1
几何常量顶带 66px、内容区 748×654、圆角遮罩 0.064×宽—
触摸坐标系SurfaceView 坐标 → ×(innerW/srcW) → display 0 坐标—
标记文件files/mirror_active.flag 存在 = 应该有镜像（看门狗据此判断）—

四、怎么跑

# 1) 开机后跑一次（起 Shizuku 服务端）
adb shell /data/local/tmp/shizuku_starter
#    或者双击项目根目录的 flip-boot.bat

# 2) 装包
bash install.sh

# 3) 启动
adb shell am start --display 1 -n com.flip.mirror/.MainActivity
#    点「开始镜像到外屏」

# 4) 退出：点右上角 ✕  → 回外屏首页，device_state 自动回 1

# 排障
adb shell ps -A | grep shizuku_server          # 0 = 服务端掉了，重跑第 1 步
adb logcat -s FlipMirror:V FlipTouchSvc:V      # 应用日志（务必用 -s TAG 过滤）

五、当前边界

  • 可用 投屏画面 / 圆角 / 悬浮控件条 / 触摸注入（UserService，零 fork）/ 无缝退出 / DPI 可调
  • 限制 开机必须跑一次 flip-boot.bat —— 这台没有免 root 的 Shizuku 自启通道（实测 ro.boot.flash.locked=1、KernelSU 守护开机不启动）
  • 限制 Shizuku 服务端会被杀；掉了之后触摸退回慢通道（每个事件 fork 一个 input）
  • 限制 通知栏/下拉菜单受外屏宽高比（1.144）限制，无法完整展示，只能靠降 DPI 缓解
  • 不可行 LSPosed + FlexUnlock（要 One UI 8.5 + 真解锁；本机 8.0 且引导锁死）
  • 不做 音频不投（单套扬声器会双重播放）；震动无法投（硬件马达）
