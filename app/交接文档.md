# FlipMirror 交接文档

> **项目**：把拆了内屏的 Galaxy Z Flip5 变成"外屏当主力机"的覆屏镜像壳
> **设备**：SM-F731U（美版 Flip5，内屏面板已物理拆除）
> **文档时间**：2026-11-10 上午
> **当前状态**：核心链路已跑通，设置界面未做

---

## 一、一句话说清这个项目

**内屏拆了，只剩外屏（748×720）。目标是让外屏显示内屏画面并可直接操作**，
效果等于"把 1080×1920 的内屏内容搬到 748×720 的外屏上，手指点外屏等于点内屏"。

**最终选定的路线**：`MediaProjection` 抓内屏 → `SurfaceView` 直出到外屏（**零编码，零花屏**），
触摸反向注入回内屏（Shizuku 执行 `input -d 0 tap`）。

## 四、核心技术方案（关键参数，改之前先看这节）

### 4.1 双屏并存 —— 这是所有方案的前提

```
cmd device_state state N
  N=0  CLOSED                 合盖，两屏都关
  N=1  TENT                   帐篷模式 → 只外屏 ON（默认状态）
  N=3  OPENED                 展开模式 → 只内屏 ON
  N=4  CONCURRENT_INNER_DEFAULT   ★ 双屏并发 → 内外屏同时 ON
```

**必须 `state 4`**，否则内屏 OFF 就没有画面可镜像。
**注意**：内屏会**自己掉回 TENT**（折叠检测），所以 App 每次启动都要重新切。

阿田 App 的「折叠模式 → 双机(双屏模式)」按钮就是这个。

### 4.2 分辨率与 DPI —— 两屏必须一致

```
wm size 748x626      # 626 = 720 - 94（状态栏高度）
wm density 340       # ★ 必须等于外屏 DPI，否则内容被缩放
```

**坑**：之前设 280 导致内容缩放 0.8 倍、四周黑边。改成 340 后正好铺满。

### 4.3 镜像链路

```
MediaProjection.getMediaProjection() → createVirtualDisplay(
     name      = "flip-mirror",
     width     = 748, height = 626,
     dpi       = 340,
     flags     = VIRTUAL_DISPLAY_FLAG_AUTO_MIRROR,   // 不要加 PUBLIC
     surface   = SurfaceView.getHolder().getSurface(),
     callback  = null,
     handler   = mainHandler
)
```

**Android 14 三道硬性约束**（缺一必失败）：
1. `getMediaProjection()` 必须在 **mediaProjection 类型的前台服务已运行之后**调用
2. `startForeground(id, notif, ServiceInfo.FOREGROUND_SERVICE_TYPE_MEDIA_PROJECTION)` —— 三参数版，二参数版抛 SecurityException
3. `resultData` **只能消费一次**，重复调 `getMediaProjection` 报 "Don't re-use the resultData"
4. 一个 MediaProjection 令牌**只能建一次** VirtualDisplay（surface 重建必须重新授权）

### 4.4 分层布局（V 提的方案，已验证）

```
FrameLayout (748x720)
├── ControlBar     y=0~94     高 94px，贴顶，按钮 32dp 圆钮
└── SurfaceView    y=94~720   高 626，topMargin=94
```

窗口级设置（要覆盖到状态栏区域）：
```java
getWindow().setFlags(FLAG_LAYOUT_NO_LIMITS, FLAG_LAYOUT_NO_LIMITS);
winLp.layoutInDisplayCutoutMode = LAYOUT_IN_DISPLAY_CUTOUT_MODE_ALWAYS;
getWindow().setDecorFitsSystemWindows(false);
// + IMMERSIVE_STICKY
```

### 4.5 触摸注入 —— 必须走 Shizuku

**KernelSU 的 su 对 App 进程做了挂载隔离**：
- `/system/bin/su` 在 App 视角**不存在**（`No such file or directory`）
- `/data/adb/ksu/bin/su` 报 `Permission denied`

⇒ **只能用 Shizuku**（它跑在 shell uid 2000 上）：

```java
// Shizuku.newProcess 是 private，必须反射
Method m = Shizuku.class.getDeclaredMethod(
        "newProcess", String[].class, String[].class, String.class);
m.setAccessible(true);
m.invoke(null, new String[]{"/system/bin/sh", "-c", "input -d 0 tap 100 200"}, null, null);
```

**坐标映射**：`外屏坐标 × (内屏宽/外屏宽)`，**目标尺寸必须传内屏实际值 748x626**
（之前写死 1080x1920 导致 y 坐标越界到 1442，注入无效）。

### 4.6 控件键也是注入

返回 / 主页 / 多任务 同样走 Shizuku：
```java
runShell("input -d 0 keyevent " + keyCode);   // 4=BACK, 3=HOME, 187=APP_SWITCH
```

## 五、踩过的坑（按踩的顺序，别再踩）

| # | 坑 | 后果 | 解法 |
|---|---|---|---|
| 1 | `getMediaProjection` 先于前台服务 | `SecurityException: requires a foreground service of type FOREGROUND_SERVICE_TYPE_MEDIA_PROJECTION` | 先 `startForegroundService`，延迟 600ms 再取 |
| 2 | `startForeground` 用二参数版 | 同上 | 用三参数版带 `FOREGROUND_SERVICE_TYPE_MEDIA_PROJECTION` |
| 3 | 重复 `getMediaProjection` | `Don't re-use the resultData` | 用 flag 保证只取一次 |
| 4 | SurfaceView 用 `PixelFormat.TRANSLUCENT` | 黑屏 | 必须 `PixelFormat.OPAQUE` |
| 5 | `VIRTUAL_DISPLAY_FLAG_PUBLIC` | 画面不一定落到 SurfaceView | 只用 `AUTO_MIRROR` |
| 6 | 内屏 OFF 时镜像 | 黑屏 + 只有控件条 | 先 `device_state state 4` |
| 7 | 内屏 DPI ≠ 外屏 DPI | 内容缩放、四周黑边 | 两屏都用 340 |
| 8 | `screencap -d 0` 报 invalid | 抓不到指定屏 | **要用 64 位 display id**（`dumpsys SurfaceFlinger --display-id` 查） |
| 9 | App 里 `Runtime.exec("su")` | `No such file or directory` | 走 Shizuku，别碰 su |
| 10 | `Shizuku.newProcess` 直接调 | 编译报 private | 反射 + `setAccessible(true)` |
| 11 | `setGeometry` 目标尺寸写死 1080x1920 | 注入坐标越界 | 传内屏实际 748x626 |
| 12 | BootReceiver 开机拉 MainActivity 到 display 0 | 干扰测试 | 已从 Manifest 删除 |
| 13 | `am start --display 1` 在双屏模式 | 被系统忽略，仍落 display 0 | 接受，用 `input -d 0` 操作内屏 |
| 14 | `Activity.setDisplay()` 反射 | 被 hidden API 拦（`setDisplay(1) failed`） | 同上，接受 |
| 15 | 授权弹窗在 626 高下按钮出屏幕 | 点不到"共享屏幕" | 小幅上滑（250ms / 80px）才露出按钮 |
| 16 | 全量 jadx 反编译 | 跑了 1h34m | 用 `--single-class <类名>` 只反编译目标类 |
| 17 | 开 `useAndroidX=false` + Shizuku 依赖 | `checkDebugAarMetadata` 失败 | 必须 `android.useAndroidX=true` |
